THE SMALLER CONTROL PLANE

No second supervisor hiding behind your supervisor.

Tunlite plans the connection, then gets out of the runtime path. The operating system executes ssh directly and owns restarts, logs, and login persistence.

DECLAREtunlite CLIconfig + validation
→

01 / ISOLATED

Failure stays local

One broken connection cannot restart every other tunnel. Each job has its own lifecycle, logs, PID, and failure state.

02 / INSPECTABLE

Nothing proprietary

No account, cloud relay, custom protocol, or embedded SSH stack. Inspect the generated plan and the native service definition.

03 / AUTOMATABLE

Designed for agents

Every operation supports stable JSON, non-interactive execution, dry-run where mutation matters, and per-item failures.

ONE DECLARATION, THREE MODES

Attached when debugging. Native when it matters.

runforeground — owned by the current terminal
startbackground — survives the terminal, not the next login
enablepersistent — starts now and returns on future logins

INSTALL THE PREVIEW

Download, verify, install.

The bootstrap selects the native archive, verifies it against the release SHA256SUMS, validates the staged binary, then atomically installs it to ~/.local/bin/tunlite.

$ curl -fsSL https://raw.githubusercontent.com/yuanyuanzijin/tunlite/master/bootstrap.sh | sh
