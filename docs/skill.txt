Tunlite v1：给 AI Agent 的安装与接入说明
===========================================

Tunlite 是单文件 Go CLI，使用系统 OpenSSH 管理本地转发、远端转发和 SOCKS 代理。
运行时不需要 Node.js、npm、账号或 Tunlite 服务端。

安装软件会修改本机。Agent 必须先告知用户版本、安装位置和来源，并取得明确同意，
不能静默安装。

macOS / Linux：

  curl -fsSL https://raw.githubusercontent.com/yuanyuanzijin/tunlite/master/bootstrap.sh | sh

Windows PowerShell：

  irm https://raw.githubusercontent.com/yuanyuanzijin/tunlite/master/bootstrap.ps1 | iex

安装脚本下载 v1.0.0-preview.1 的平台二进制，并使用同一 GitHub Release 中的
SHA256SUMS 校验。它只安装 CLI，不创建 Connection，也不启动任何持久服务。

安装后先验证运行时契约：

  tunlite version --json
  tunlite capabilities --json
  tunlite schema cli

Agent 的所有操作使用 --json --non-interactive；修改前优先使用 --dry-run。公开监听、
远端转发、删除、覆盖导入和迁移回滚必须获得用户明确批准。批量操作退出 6 表示部分
失败，必须检查每个 results[] 项。
